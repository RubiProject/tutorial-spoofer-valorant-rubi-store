# Formatação do Windows

Como reinstalar o Windows

> **⚠️ Aviso:** Reinstalar o Windows resultará em perda de dados.

**Instalar ISO**

> **ℹ️ Info:** Você pode optar por reinstalar o Windows 10.

> [Download Windows 10](https://www.microsoft.com/en-us/software-download/windows10)

1. Baixe a ferramenta de criação de mídia acima e clique em **Baixar agora**
2. **Ferramenta de criação de mídia** aberta
3. Selecione **Criar mídia de instalação (unidade flash USB, DVD ou arquivo ISO) para outro PC**
4. Use as opções recomendadas
5. Selecione **o arquivo ISO**
6. Selecione o diretório
7. Após a conclusão do ISO do Windows, baixe o Rufus

[Download do Rufus](https://github.com/pbatard/rufus/releases/download/v4.5/rufus-4.5.exe)

1. Abra o Rufus e selecione estas opções
2. Pressione Selecionar e vá para o diretório onde você baixou o dispositivo ISO
3. Selecione seu USB (8gb+)

![Rufus Opções](https://divine-cheats.gitbook.io/spoofer/~gitbook/image?url=https%3A%2F%2F18024476-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FmnB9nCeIgrnqe5WWCgVo%252Fuploads%252Fq0d1YDuH59C98agqIBpC%252Fimage%2520%2812%29.png%3Falt%3Dmedia%26token%3Dc8353161-bd3b-4caa-8b14-61199c6aaecd&width=768&dpr=1&quality=100&sign=2dd6cbdf&sv=2)

Selecione as duas últimas opções

![Rufus Seleção](https://divine-cheats.gitbook.io/spoofer/~gitbook/image?url=https%3A%2F%2F18024476-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FmnB9nCeIgrnqe5WWCgVo%252Fuploads%252FE2tO1AazQlo1gmJE8QUD%252Fimage%2520%2813%29.png%3Falt%3Dmedia%26token%3D0b5d2c52-d37f-446e-84d3-785fff02eadd&width=768&dpr=1&quality=100&sign=49b2f9b7&sv=2)

1. Pressione OK e aguarde o Rufus concluir a formatação USB
2. Após a conclusão, arraste este [arquivo](https://mega.nz/folder/jMlkxShB#gZH6tedefqJhJ-RxZW7b1g) para dentro do USB
