# Desativar o Windows Defender

Como desabilitar o Windows Defender

#### Desativar o Windows Defender manualmente <a href="#disable-windows-defender-manually" id="disable-windows-defender-manually"></a>

1. Selecione Iniciar e digite "Segurança do Windows"
2. Selecione o aplicativo Segurança do Windows nos resultados da pesquisa, vá para Proteção contra vírus e ameaças em Configurações de proteção contra vírus e ameaças selecione Gerenciar configurações
3. Desligar a proteção em tempo real

#### Desabilitar o Windows Defender com dControl <a href="#disable-windows-defender-manually-1" id="disable-windows-defender-manually-1"></a>

#### [447 KBdControl.ziparchive](https://1747526905-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FIRlbgGEe6FZJRx7luQsK%2Fuploads%2FPzHvDvms4BIrjTrj326l%2FdControl.zip?alt=media\&token=4ba74f9b-97ac-45cf-a26c-07b3817afcd8) <a href="#disable-windows-defender-manually-2" id="disable-windows-defender-manually-2"></a>

1. Baixe **o dControl** acima[ ](https://www.sordum.org/files/downloads.php?st-defender-control)
2. Descompacte os arquivos
3. Execute **dControl.exe**
4. Desativar o Windows Defender
