# Desativar atualizações do Windows

Como desabilitar as atualizações do Windows

[Bloqueador de atualizações de 1MB.ziparchive](https://1747526905-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FIRlbgGEe6FZJRx7luQsK%2Fuploads%2Fnw7IXNyBm4O8MaKr94cJ%2FUpdate%20Blocker.zip?alt=media\&token=658c03b1-f99a-4830-836d-d562a904559d)

1. Baixe o Windows **Update Blocker** acima
2. Descompacte os arquivos
3. Execute **Wub\_x64.exe**
4. **Desabilite** as atualizações do Windows e **aplique agora**
