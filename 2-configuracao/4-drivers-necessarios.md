# Drivers Necessários

**Baixe o Visual C++ Redistributable Runtimes All-In-One**

[Visual C++ Redistributable Runtimes All-in-One (abril de 2022) DownloadTechPowerUp](https://www.techpowerup.com/download/visual-c-redistributable-runtime-package-all-in-one/)

1. Baixe o Visual C++ Runtimes acima
2. Descompacte o arquivo
3. Execute **install_all.bat** como administrador
4. Reiniciar o PC
